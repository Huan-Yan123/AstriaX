# AstriaX 1.0.3

- 安装包支持直接覆盖原安装目录更新，无需先卸载；保留实例、共享运行时、配置与插件数据。
- 同版本支持覆盖修复，拒绝降级安装；覆盖前检查程序占用并备份旧程序与用户配置。
- 设置拆分为常规、应用更新、存储、日志与反馈四个页面，关闭行为新增“每次询问”。
- “工作区”改为“实例”，非实例页面隐藏实例侧栏；左上角图标菜单支持悬停说明，新增前进、后退与侧栏收起。
- AstrBot、NapCat 下载弹窗显示进度，失败时展示具体原因；AstrBot 安装依赖阶段显示实际输出。
- 新增跟随系统、直接连接及手动 HTTP/HTTPS 代理，统一用于源检测、版本查询和资源下载。
- 修复代理或加速工具下 GitHub 直连被误报不可用：使用系统信任证书，并展示底层 TLS、代理连接错误。
- 删除已安装版本时立即显示处理中状态；版本移出后后台清理文件，退出会暂停清理并在下次启动继续，避免大目录删除阻塞退出。
- 补齐设置图标，AstrBot 与 NapCat 使用上游 Logo。

更新方法：退出启动器并停止实例，运行 `AstriaX_1.0.3_x64-setup.exe`，选择原安装目录即可覆盖更新。通过设置页执行“退出并安装更新”时，应用自动传入当前安装目录。
