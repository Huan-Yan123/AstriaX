# AstriaX Launcher 0.2.1 开发日志

## 2026-10-07

### 本次修复

- WebUI 视图增加加载超时、关闭期间的过期加载保护和“最后一次点击优先”，避免慢加载的旧页面覆盖新选择、关闭后视图又复活。
- WebUI 外框尺寸保持不变，页面内容默认缩放至 85%，让控制台首屏显示更多内容；缩放仅作用于嵌入网页。
- NapCat WebUI 改为 `/webui/` 路由，并异步读取实例 token 后 URL 编码；AstrBot 仍使用服务根路径。
- 启动前检测目标端口占用，已占用时明确拒绝启动，避免创建第二个 NapCat 或把无关监听服务当作本实例。
- WebUI 工具条显示当前可见实例，而不是把隐藏视图数量误报成“运行中”；同实例请求期间按钮显示“连接中”，快速重复点击被抑制。
- 实例卡片在记录状态可能滞后的情况下仍允许尝试打开有效端口，具体可达性由主进程确认并给出错误原因。
- 更新备份清理和列表新增异步实现，并将启动/IPC 调用切换到异步路径，避免大量目录同步遍历阻塞主窗口。
- 压缩包探测改为异步读入单份缓冲区并复用，限制导入包最大 512 MiB、元数据解压最大 16 MiB，降低超大 ZIP/压缩炸弹造成卡死或内存耗尽的风险。
- 修正主进程 IPC 模块在 ESNext 模块目标下的 CommonJS `os` 导入写法，以及一个无效的可选参数默认值声明。
- 版本号更新为 0.2.1，新增本开发文档与日志。

### 设计取舍

- 端口探测不具备服务身份认证能力；因此只用来判断是否有响应，启动时的占用端口采取拒绝策略。若 NapCat 已在 QQ 进程中独立存活，用户可以通过 WebUI 按钮连接，但不会再通过启动按钮生成另一份进程。
- NapCat 官方 WebUI 地址包含 `/webui/?token=...`；本版按实例读取本地配置，不注入新的默认 token。

## 2026-10-08

- 修复 NapCat 进程仍驻留在 QQ.exe 时误删实例的缺陷：停止流程现在必须确认实例端口释放，否则停止/删除/切换版本/备份等操作会中止，实例记录和文件继续保留，避免释放端口后新实例误连旧 NapCat。对于证据不足的监听进程继续采取保守策略，不强杀 QQ。
- 修复 `webui:open` 只凭端口可连就打开页面的问题：没有在当前启动器会话成功启动、且进程管理器也未确认运行的实例，不会连接复用端口上的残留服务。
- 下载任务改为无卡片底色的分隔式任务行，进度轨道加高、上下留白增加；使用生图模型按现有角色参考生成四帧跑步动作表，透明背景，角色随进度移动并循环播放帧动画，尊重系统减少动态效果设置。
- 增加“对外监听进程仍占端口时拒绝删除并保留实例记录和目录”的回归测试；相关 IPC 用例和脱链进程用例通过，生产构建通过。

- AstrBot pip 进度速率改用 Mbps 显示，和任务管理器的网络单位一致；检测到 `Using cached` 时显示本地缓存读取速度，避免把磁盘读取伪装成网络下载速度。
- 实例列表从多张圆角卡片改为清晰的服务行，操作与状态横向对齐，窄窗口自动换行；配色收敛为雾青灰底和深海青蓝主色，减少卡片套卡片的生硬感。
- 内嵌 WebUI 缩放调整至 75%，固定窗口尺寸下增加首屏可见内容。
- UI 参考 AstrBot Launcher 的实例管理边界和 Mewl 的本地服务列表信息组织方式；未复制仓库代码或品牌资源。
- 根据用户提供的 AstriaX Logo 修订色板：由青灰主色回到 Logo 的钴蓝/天蓝/蓝紫体系，并将选中、焦点、悬停颜色统一连接到主题变量。
- 按用户要求推翻全应用旧布局：主导航加文字标签；下载与镜像源、设置、备份改为分隔式信息行；设置面板改成宽屏双栏、窄屏单栏；统一首次启动、创建和通用弹窗的尺寸、圆角、边框与阴影，并补齐输入焦点样式。
- 修复打开 AstrBot 却显示 NapCat：切换 WebUI 时销毁旧实例的 WebContentsView，避免 Electron 子视图堆叠/显隐状态让旧 NapCat 页面重新露出；关闭当前视图后回到启动器，不自动显示其他实例页面。
- AstrBot 启动同时设置 `DASHBOARD_PORT` 环境变量并保留 `--port` 参数，让 Dashboard 监听端口与实例记录、启动器显示端口一致，避免浏览器访问错误端口。
- 改善 AstrBot 安装过程的可见性：显示已经发现的依赖数量、当前阶段和当前包下载字节数。
- pip 安装启用官方 `raw` 下载进度输出，解析每个 wheel 的字节变化并计算平滑网速，界面显示实时速度。
- 说明安装总百分比是按 pip 阶段估算的进度，不是剩余时间；长时间没有 pip 输出时，给用户解释可能原因并提示可取消后切换 Python 源。
- 实机 NapCat 注入生命周期、浏览器 WebUI 登录态和 Windows 打包行为需要在目标 Windows 环境确认。
